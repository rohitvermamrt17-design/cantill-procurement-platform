# Cantill Procurement Platform

An intelligent procurement management platform designed to streamline purchasing workflows, automate procurement operations, and improve policy compliance.

## 🚀 Overview

Cantill Procurement is a procurement management application that brings purchase requisitions, sourcing workflows, policy management, and procurement operations into one centralized platform.

The application focuses on simplifying procurement processes through structured workflows, bulk data processing, and policy-driven decision-making.

## ✨ Key Features

- **Buyer Workspace:** Centralized workspace for managing procurement requests.
- **Policy Studio:** Configure and manage procurement policies.
- **Purchase Requisitions:** Manage and track purchase requisitions.
- **Bulk CSV Processing:** Import and process procurement records in bulk.
- **Contract Management:** Organize and manage contract-related records.
- **Audit Trail:** Track procurement activities and operational events.
- **Workflow Routing:** Route procurement requests through defined workflows.
