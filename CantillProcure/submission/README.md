# Blind-test submission outputs

This folder is reserved for the three final CSVs required by the challenge. On blind-test day:

1. Export decisions from the frozen v5.0 policy run.
2. Approve the amendment in Policy Studio, then export decisions again.
3. Export preferred suppliers for the date specified by Cantill.ai.

Name the files clearly, e.g. `run1_v5.csv`, `run2_amended.csv`, and `preferred_suppliers.csv`. Do not use the sample/demo CSVs as blind-test outputs.
